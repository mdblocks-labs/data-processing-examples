# Client campaign report

The question this page answers: **which campaigns should this client scale,
hold or cut this week, and what changed since the last report?** The totals
lead, then the action list, which filters and sorts, and opens each campaign
on its four weeks and its figures in the last report. Then what changed since
that report, the rows that need a look before sending, each export's totals
to tie to its source, and which steps this run did again.
